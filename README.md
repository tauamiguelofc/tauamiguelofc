## 🚀 Projetos

### 🔐 N2 Bank
> Plataforma desktop de pagamentos (MVP White Label) construída com **Rust + Tauri**. Integra-se a uma API de Banking as a Service (BaaS) para transações Pix e P2P, com livro-razão local criptografado e interface inspirada no MetaMask.

*   **Segurança:** SQLite criptografado via Keychain.
*   **Performance:** Desktop nativo com Tauri.
*   **Status:** Em desenvolvimento ativo.

🔗 **[Acessar repositório →](https://github.com/tauamiguelofc/n2-bank)**

### 🛩️ RX-12 "Eletro-Streak" 🔒 *Privado*
> UAV de asa fixa de alta altitude e longo alcance. Programa pessoal de engenharia focado em arquitetura de sistemas, controle de voo e modelagem aerodinâmica, com alvo declarado de conformidade com **MIL-STD-810H** e **DO-178C**.

*   **Documentação:** SSD (System Specification Document) · REV. B
*   **Escopo:** Flight Control · Telemetria (LoRa/MAVLink) · Propulsão Elétrica · CAD
*   **Nota:** Repositório privado. Especificações técnicas, CAD e firmware não são públicos por opção de design do projeto.

`C/C++` · `RTOS` · `MATLAB` · `CFD` · `Sistemas Embarcados`
